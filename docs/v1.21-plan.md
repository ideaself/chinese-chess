# v1.21 开发计划：训练闭环与体验升级

> 制定于 2026-09-03（v1.20.0 发布后）
> 模型：GLM 5.3 Flash（glm-5.3-flash / opencode-go/glm-5.3-flash）

## 背景与主题

v1.20.0 完成了性能优化与代码清理。本版本主题：**把习题、残局、错题、棋力分各自孤立的数据串成「训练闭环」**，并以主页「每日一题/今日训练」为统一入口提升粘性。

- **e2e 移动套件陈旧**：`scripts/e2e/mobile.cjs` 仍按 v1.18 前的 `.bottom-bar` 导航编写，v1.19 改为「首页三按钮 + 全屏页」后 17 项失效（基线 v1.20.0 同样失败，与本次改动无关）。需按新导航重写。
- **e2e 基线其他旧失败**：对局角色 1 项（提示三步箭头 arrows=6 vs moves=3）在基线即失败（基线 3 项中 2 项实为拆棋引擎时序 flaky），待单独排查。
- **SecureStore 运行时验证**：编译/签名已通过；设备当时断连，待真机连回后用 WebDAV 分组验证密码保存/迁移。
